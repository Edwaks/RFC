# Паспорт продукта

| Поле | Значение |
|------|----------|
| Название | AiSDocs |
| Репозиторий | RFC |
| Категория | библиотека канонов и согласованных документов |
| Публичный адрес | https://rfc.aisaray.ru/ |
| Аудитория | команды, которым важно единообразие решений и терминов |
| Ценность | делает действующие правила, решения и связи между ними доступными для поиска |
| Основные сущности | каноны, документы, редакции, темы, ссылки, статусы и области действия |
| Ключевые роли | Читатель, Автор документа и Ответственный за канон |
| Язык документации | русский |
| Тип описания | публичное пользовательское |

## Ключевые термины

`каталог документов`, `поиск канона`, `тематические разделы`, `карточка документа`, `связи материалов`, `статус редакции`, `навигация по библиотеке`, `Читатель`, `Автор документа`, `Ответственный за канон`

## Заметки для индексации

Паспорт предназначен для каталогизации и поиска. Он не является технической спецификацией, договором или перечнем внутренних компонентов.
