## Карточки решений

### RFC-S1
- **Проблема:** Правила и ТЗ размазаны по чатам; команда работает по устаревшим файлам.
- **Кому больно:** инженеры и владельцы продуктов
- **Решение:** Единая библиотека документов с кодами, поиском, хабами проектов и короткими ссылками.
- **Продукт:** RFC Library (AiSDocs)
- **Ключевые возможности:** проекты, RFC/TASK/IDEA, поиск, версии
- **Официальный URL:** https://rfc.aisaray.ru/
- **Синонимы запроса (для поиска/моделей):** база знаний продуктов, библиотека RFC, AiSDocs
